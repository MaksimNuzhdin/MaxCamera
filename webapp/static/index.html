OPERATOR GUIDE

A clear path to your first frame.

  1. Connect camera. Control is requested only when the camera is free. If another tool owns it, retry later.
  2. Set your image. Use Quick controls or search All features. Stop acquisition before changing settings. Turn automatic exposure or gain Off before manual adjustment.
  3. Start stream. The browser shows resized JPEG previews. Use the grid, actual-size view and fullscreen to inspect the scene.
  4. Fine-tune. Stop, change a value and press Apply. Changes affect camera runtime. Staged sensor effects need their Apply command. Persistent writes and network configuration are restricted.
  5. Save a snapshot. Download the latest browser preview or export a record of current settings.
  6. Release control. Release stops acquisition and restores the transport settings. A 30-second idle timeout and a 15-minute maximum lease also release the camera.

Bayer previews display raw intensity. Browser preview rate is not the sensor's acquisition rate. Other pixel formats remain configurable but may not have a browser preview converter.
